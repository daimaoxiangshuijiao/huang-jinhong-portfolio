# 黄进鸿 · AIGC 影像创作作品集

展示个人视频作品、角色与视觉世界概念、工作经历和三个可实际操作的交互实验。

- **《末世影》**：本人提供的完整视频，支持播放、声音、进度定位及单独打开。
- **《归巢协议》**：原创 AI 协作角色与场景概念、四个可探索场景及可旋转的精细三维装甲形态；目前为概念开发，尚未制作成短片。
- **分镜导演台**：本机图片导入、分镜编排、运镜与字幕、预演和静音动态视频导出，以及项目、分镜图、CSV、SRT 导出。
- **记忆核心**：实时三维参数创作、收藏、草稿恢复和海报导出。
- **跃迁航迹校准**：画圆评分、回放、历史记录和记录卡下载。

工作经历依据本人简历整理。网站包含本人提供的简历与联系方式；实验草稿和收藏保存在当前浏览器，视频导出取决于浏览器能力。

## AI 协作与模型来源

网站代码、交互实验及部分角色和场景视觉在 AI 辅助下完成。精细三维角色使用 Tencent Hunyuan3D-2mini 本地三维重建和多视角材质投影，背部及侧面由 AI 补充设计，不标称手工雕刻或单图精确还原。详细来源、工具版本、限制及署名保存在 [角色清单](assets/character-asset.json) 和 [资产说明](assets/recorder-asset-notice.txt)。
